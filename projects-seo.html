Digital Culture IT Solutions designs, builds and supports cloud infrastructure and websites for small and mid-sized businesses in Bergen County, NJ and the NYC metro area. Each project below starts with a real business problem and shows the solution delivered: secure AWS networking and storage, auto-scaling and load balancing, VMware Cloud on AWS, static hosting on S3 and CloudFront, locked-down EC2 management with Systems Manager, and production-ready AWS account governance. The source and documentation for each build are public on GitHub.

AWS · Networking & Storage

Secure VPC + Shared Storage Infrastructure

Business Problem

Client needed a production-grade AWS environment with private compute and shared file storage — no public IPs, no SSH exposure, and no bastion host to manage.

IT Solution

Built a custom VPC with public/private subnets, deployed EC2 accessed exclusively via AWS Systems Manager (no open ports), and attached EFS for shared storage across instances.

IT Solution

AWS · Security

Private EC2 Management — No SSH, No Bastion

Business Problem

Security audit flagged open SSH ports and a bastion host that required its own patching and key management. Compliance required zero inbound ports on production instances.

IT Solution

Deployed private EC2 instances with no public IP and no inbound security group rules. Full shell and remote management via AWS Systems Manager Session Manager — audited, logged, IAM-controlled.
